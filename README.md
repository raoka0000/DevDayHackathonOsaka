# PV Palette（仮称）

複数の画像と伝えたい雰囲気から、オリジナル音楽付きの15秒PVを作るWebアプリ。
3時間のハッカソンで実装し、**Cloudflareで公開したサイトを発表時に操作する**。

## ユーザー体験

1. 画像を3〜5枚選ぶ。
2. タイトル、紹介文、雰囲気（爽やか・かっこいい・感動的など）を入力する。
3. AIが映像構成・テロップを作り、音楽を生成する。
4. サイト上で、画像の動き・テロップ・音楽が同期したPVを再生する。

主な用途は、店舗・商品・イベント・作品の紹介。画像しか持っていない人でも、短いプロモーションを作れることを目指す。

## 今回の完成条件

- Cloudflareの公開URLから利用できる。
- 選択した画像と入力内容を使って構成・テロップを生成できる。
- 外部サービスで生成した音楽をPVと一緒に再生できる。
- 読み込み中・失敗時・再試行の表示がある。
- 発表用の完成例があり、事前生成であることを明示して再生できる。

初期版はブラウザで再生するPV。MP4書き出し、ログイン、課金、履歴、SNS投稿、画像自体のAI動画化は追加機能とする。
