# PhotoChord（仮称）

**写真から音楽のたたき台を作り、自分とAIで編集できるWebアプリ。**
3時間のハッカソンで実装し、Cloudflareで公開したサイトを発表時に操作する。

たとえば結婚式の写真を選ぶと、AIが「祝福・明るさ・温かさ」という印象を提案し、
明るいコード進行の伴奏が入った状態から始められる。
ユーザーはコードやテンポを直接変えたり、「もう少し感動的に」とAIに頼んだりできる。
画像の印象は一つの提案として扱い、ユーザーが変更できる。

## ユーザー体験

1. 写真を1〜5枚選ぶ。
2. AIが画像の印象と、キー・テンポ・8小節のコード進行を提案する。
3. 分析設定からメロディー・コード伴奏・ベースの8小節を自動作曲し、適用して再生する。
4. 小節ごとのコード、テンポ、伴奏パターンを簡単に編集する。
5. AIに変更を依頼し、提案を試聴してから適用する。元に戻すこともできる。
6. 編集した曲をMIDIファイルとして書き出す。

## MVPの完成条件

- Cloudflareの公開URLから利用できる。
- 画像に基づくAIの提案から、8小節のコード伴奏を生成・再生できる。
- コード・テンポ・伴奏パターンの変更が実際の音に反映される。
- AIへの変更依頼をプレビュー・適用・取り消しできる。
- 編集後の内容をMIDIとしてダウンロードできる。
- 読み込み中・失敗・再試行を表示し、サンプルはサンプルと明示する。

音楽は音符・コード・テンポを保持する構造化データとして扱う。
音声生成APIは必須にせず、画像を扱うAIの提案からアプリが音符を組み立てて再生する。

## 初回準備（Windows / macOS共通）

1. [Node.js公式サイト](https://nodejs.org/)から **Node.js 24 LTS** をインストールします（最低22.12以上）。WindowsではインストーラーのnpmとPATH設定を有効にします。
2. ターミナルを開き直し、`node -v` と `npm -v` が表示できることを確認します。
3. Gitでこのリポジトリを取得するか、ZIPを展開します。**package.jsonのあるフォルダー**をターミナルで開きます。

WindowsのPowerShell例（パスは自分の配置場所に変更）：

```powershell
cd "C:\Users\自分の名前\Desktop\DevDayHackathonOsaka"
npm.cmd ci
npm.cmd run dev
```

macOSのターミナル例：

```sh
cd "/Users/自分の名前/Desktop/DevDayHackathonOsaka"
npm ci
npm run dev
```

`npm run dev` は初回ビルド後、写真分析用Worker（内部ポート8788）とViteをまとめて起動します。画面用URLから写真分析も使えます。APIキーは `.dev.vars` の `OPENAI_API_KEY` に設定してください（[準備手順](docs/OPENAI_IMAGE_ANALYSIS.md)）。設定変更後は再起動します。キーなしでも固定サンプル・手動感情生成・編集は利用できます。8788が使用中なら既存の開発サーバーを停止してください。

表示されたURL（通常 **http://localhost:5173**）をChrome / Edgeなどのブラウザで開きます。ポートが使用中ならViteが表示する別のURLを使ってください。停止はターミナルで **Ctrl+C**。次回からは `npm run dev` だけで起動できます（Windowsは `npm.cmd run dev`）。

Windowsで「スクリプトの実行が無効」と表示される場合は、上記のように `npm` の代わりに **npm.cmd** を使ってください。実行ポリシーの変更やWSLは不要です。`node` が見つからない場合はNode.jsをインストールしてターミナルを開き直してください。macOSのnode_modulesをWindowsへコピーせず、それぞれの端末で `npm ci` を実行します。

## 操作手順

1. 初期表示の固定サンプルで「再生する」を押す（写真の選択なしでも利用可）。
2. JPEG / PNG / WebPの写真を1〜5枚選択し、「写真から提案する」を押すとOpenAIに送信して8小節の提案を受けます。各10 MiB、合計20 MiBまで。実接続は未検証です。
3. 小節ごとのコード、テンポ、伴奏パターンを変更して再生する。編集中は演奏が止まります。
4. 「元に戻す」で最大30回の直前編集に戻る。
5. 「MIDIを書き出す」で `photochord.mid` を保存し、MIDI対応DAWなどで開く。

画像の選択だけでは曲を置き換えません。提案の適用時に曲と音符を置き換え、元に戻せます。「サンプルを読み直す」は編集中の曲を固定サンプルに置き換えます。ブラウザの再読み込みで曲が消えるため、必要な結果はMIDIで書き出してください。MIDIに写真は含みません。

## 感情から伴奏を生成する

写真・コード編集画面で「明るい・温かい・穏やか・切ない・力強い・幻想的」を複数選び、「選んだ感情で生成する」を押します。テンポ・伴奏パターン・コード進行を確認して「再生成を適用」で反映します。未選択では生成できません。

ローカルのプリセットを組み合わせる生成で、画像分析・AIは使いません。写真なしでも利用できます。最初のトラックの全音符を置き換え、音色・追加トラックは保持します。選択だけでは曲は変わらず、適用後は元に戻せます。生成した音符は通常どおり編集・再生・MIDI出力できます。

## ピアノロール（イシュー #1）

写真・コード編集画面の「MIDI編集画面を開く」から専用画面 `#/midi` に移動します。「写真・コード編集に戻る」で戻れます。画面の往復では曲・写真・Undo履歴を保持し、再生は停止します。再読み込みでは編集内容は消えます。

専用画面の「音符を直接編集」には現在の全音符を表示します。縦軸はMIDI 48〜84（C3〜C6）、横軸は8小節・32拍です。目盛りの `2.3` は2小節目の3拍目を表します。グリッド内を縦横にスクロールでき、表示だけでは音符は変わりません。

- 空白をクリックすると1拍・ベロシティ78の音符を追加します。末尾からはみ出す追加は拒否します。
- 音符をドラッグすると半音単位・選択中のグリッド幅で移動します。右端をドラッグすると同じグリッド幅で長さを変更します（初期値0.25拍）。最短0.25拍、終端32拍です。
- 音符を選択し、音高・開始拍・長さを入力して「音符に適用」でも変更できます。Tabで選択でき、Delete / Backspaceまたは「削除」で削除します。Escape、ポインター操作の中断はドラッグを取り消します。
- 既存の0.45拍・3.8拍は移動・表示では維持します。長さ入力はこれらの値も扱えるため任意精度ですが、0.25拍以上に限ります。音符の強さは1〜127の数値で編集できます。下段の強さレーンから音符を選択することもできます。
- 同音高の重なり・範囲外の変更は理由を表示して拒否します。異なる音高の和音は許可します。全音符を削除しても無音の8小節として再生・出力できます。
- 追加・移動・長さ変更・削除は、それぞれ1操作でUndoできます。ドラッグ中は確定せず、マウスを離したときだけ履歴に入ります。
- コード変更では**開始拍が対象小節にある音符**、パターン変更では全音符を再生成します。確認欄の適用／キャンセルを選んでください。小節をまたぐ音符も開始小節の所有として扱い、残る音符と同音高で重なる再生成は拒否します。Undoは設定と音符を一緒に戻します。
- テンポ変更は音符を保持します。音符編集開始時は演奏を止め、再生位置を先頭に戻します。

正本は `Track.notes` です。画面・再生・MIDIはこの配列を使い、コード設定から毎回再計算しません。編集内容はメモリ内のみです。

検証：型チェック・8件の自動テスト・本番ビルド、ローカルブラウザで数値編集、ドラッグ移動・長さ変更、追加、削除・Undo、重複拒否、コード再生成の取消・適用・Undo、再生・再再生・停止、MIDIダウンロードを確認しました。音声実聴・外部DAW・公開URL・Windows実機は未確認です。詳しくは [#1の実装・検証記録](docs/issues/1-implementation.md) を参照してください。

## MIDIスタジオの音色・編集操作

専用画面 `#/midi` の音源ブラウザから、ピアノ・ギター・ストリングス・太鼓・タム・シンセドラムの6種類のサンプル音源と、エレピ・オルガン・パッド・プラック・ベルの5種類の内蔵シンセを選べます。初期音色はFluidR3のグランドピアノです。「サンプル音源」と「内蔵シンセ」を切り替え、音色を選んで「再生」を押すと、現在の編集音符をその音色で演奏します。サンプルは必要な音色だけ初回に読み込み、読み込み中も停止・切り替えできます。失敗時は再生ボタンで再試行するか、内蔵シンセに切り替えてください。

音色変更は再生を停止し、音符とテンポを保持します。Undo対象に含み、画面移動でも保持します。「サンプルを読み直す」は曲と音色を初期状態（FluidR3のグランドピアノ）に戻します。MIDIは音色に応じたGeneral MIDIの楽器指定（Program Change）を含みますが、音源自体は含まれず、出力先によって響きが変わります。打楽器3音色は音高のある楽器で、標準ドラムキットではありません。

グリッド幅（1/16・1/8・1/4）、横方向ズーム、消しゴム、音符の強さ入力に対応します。矢印キーで選択音符の音高・開始拍、Shift＋左右で長さを変更できます。Spaceは入力欄・ボタンにフォーカスがないときに再生・停止します。テンポ欄はEnterまたはフォーカスを外して確定します。上段のアレンジメントは曲全体の音符を表示する概要です。

サンプル素材はFluidR3（Frank Wen）、ブラウザ向け変換・配布はBenjamin Gleitzman / [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts)。[CC BY 3.0 US](https://creativecommons.org/licenses/by/3.0/us/)で利用し、作者・出典・ライセンスを画面にも表示します。素材ファイルは変更していません。固定版・サイズ・SHA-256・ライセンス原文は [音源素材の出典](public/soundfonts/FluidR3_GM/SOURCE.md) と同フォルダーのmanifest/ライセンスを参照。6音色で約12.4MBを静的配信します。内蔵シンセ5音色はアプリ独自のWeb Audio設定で、追加の音声素材を使いません。

## 複数の楽器を重ねる

MIDI専用画面で「＋ 楽器を重ねる」を押すと、選択中の音符を別トラックにコピーします。新しいトラックを選択して音源ブラウザから楽器を選び、「再生」で全トラックを同時に演奏できます。「＋ 空トラック」は音符なしで追加します。最大8トラック、8小節・共通テンポです。

- トラックの名前またはクリップをクリックすると、そのトラックのピアノロールと音色を編集できます。別トラックの音符は変わりません。
- 各トラックの音量、M（ミュート）、S（ソロ）を操作できます。ソロがある場合はソロのトラックだけを演奏し、ミュートはソロより優先します。変更やトラック選択時は演奏を停止します。
- 追加・削除・音色・音符・ミキサー変更はUndo対象です。音量ドラッグは離した時に確定します。最初のトラックは削除できませんが、ミュートや音符削除はできます。
- 複数トラックのMIDIはFormat 1で出力し、トラック名・別々のチャンネル・楽器指定・音量を含みます。ミュート/ソロによる再生対象を反映するため、全トラックを残す場合はM/Sを解除して書き出します。
- 写真・コード編集画面のコード/パターン再生成は最初のトラックだけを置換し、追加トラックは保持します。テンポは全トラック共通です。「サンプルを読み直す」は追加トラックも含めて初期状態に戻します。

音符はトラックごとに保持し、再生とMIDI出力で共用します。同じ音高を異なるトラックで重ねることができます。打楽器も音高付きの楽器として扱い、標準ドラムキット専用チャンネルは使用しません。

## 再生位置を指定する

MIDI画面では、ピアノロール上部の拍目盛りをクリックして再生位置を選べます。Tabで目盛りに移動し、Enter／Spaceでその位置を指定することもできます。

停止中は選択位置を保持して「再生」から開始します。再生中に移動すると、それまでの演奏を止めて全トラックを新しい位置から再開します。「一時停止」は位置を保持、「■ 停止」は先頭に戻します。「↺ 最初から再生」は先頭から演奏し直します。Spaceも再生／一時停止です。

位置変更では音符・Undo履歴・MIDIの内容を変更しません。MIDIは指定位置によらず全8小節を書き出します。編集・画面移動時には従来どおり演奏を停止して先頭に戻します。写真・コード編集画面の進行バーもクリックまたは左右キーで位置指定できます。

## 写真から演奏内容まで自動生成

写真分析の結果を受け取ると、AIが提案したテンポ・コード進行・伴奏パターンから、アプリがメロディー・ピアノ伴奏・ベースの3トラックの音符を自動生成します。「生成した音楽を適用する」→「再生する」で聴けます。適用は現在の全トラックを置き換え、Undoできます。MIDI画面で各音符を編集でき、MIDI出力にも全パートを含みます。音符はローカルの作曲ルールによる生成です。生成後のコード／パターン変更は伴奏だけが対象で、メロディーとベースは自動追従しません。

確認：型チェックを含む本番ビルド、14コード×2パターン×3テンポの84設定で3パートの音符検証・MIDI Format 1出力・Undo・コード編集時の追加トラック保持、不正設定の拒否を確認。今回の変更について、実画像API・ブラウザ操作・音声実聴・外部DAW・公開URLは未確認です。起動手順は上記 `npm run dev` を利用します。

## 複数写真とスライドショー

写真は合計1〜5枚まで、複数同時選択または追加選択できます。一覧の矢印で順番を変え、不要な写真を削除してから「写真から提案する」を押します。分析待ちは写真を大きく表示し、2.5秒ごとに切り替えます。

曲全体は8小節のまま、写真の順番で小節をできるだけ均等に配分します。例えば3枚なら1〜2、3〜5、6〜8小節です。同じ割当をAIに渡し、写真ごとの印象と切替に合うコード進行を提案させます。「生成した音楽を適用する」の後に再生すると、音声の再生位置に合わせて写真が切り替わります。テンポ変更や途中再生にも追従します。音符は従来どおりアプリが組み立て、編集・MIDI出力できます。

生成に使った写真は曲と一緒にメモリ内で保持し、Undoでも戻ります。次の写真の選択・並べ替えだけでは現在の曲やその写真を置き換えません。写真は再生成・適用で反映します。写真はMIDIに含まれません。

今回の確認：型チェックを含む本番ビルド、ローカルプレビュー起動・ブラウザ初期表示、1〜5枚の小節割当、モック応答を使ったAI送信順・割当の確認、3トラック音符生成・検証、MIDIヘッダーを確認しました。複数写真を使うブラウザ一連操作・実AIによる音楽の適合性・音声実聴・公開URLは未確認です。既存の起動・デプロイ手順に変更はありません。

スライドショーは生成待ちと写真付きの曲の再生開始時に全画面表示になります。「フルスクリーン」でも開けます。下部の再生バーで位置を変更し、再生／一時停止・停止を操作できます。「閉じる」またはEscで通常表示に戻ります（曲の再生は継続）。Fullscreen API非対応時はブラウザの表示領域全体を使います。生成待ちは再生操作を無効化し、完了後に提案画面へ戻ります。

フルスクリーン変更の確認：型チェック・本番ビルド・差分の形式チェックを実施。ブラウザ自動操作では画像選択ダイアログを取得できなかったため、全画面での一連操作・実音声・スマートフォン実機は未確認です。

## 写真ごとの音楽の変化

写真分析では、各写真の担当小節に合わせてテンポ・伴奏パターン・コード伴奏／メロディー／ベースの楽器を提案します。生成結果を適用すると「写真ごとのテンポ・楽器」で個別に調整できます。写真の切り替わりで演奏設定が変わり、途中再生やMIDI出力にも反映します。テンポ・楽器の編集は音符を保持し、伴奏パターンの編集は確認後に伴奏の全音符を再生成します。Undoできます。MIDI画面の音色選択は対象パートの全写真へ、全体テンポの編集は全写真へ適用します。既存の曲は写真から再生成・適用すると新しい提案を利用できます。
