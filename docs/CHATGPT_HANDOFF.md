# ChatGPTへの開発依頼文

リポジトリにアクセスできるChatGPT / Codexで、以下を使う。
ファイルを参照できない場合は、READMEとdocsの内容も渡す。

```text
このリポジトリのPhotoChord（仮称）を実装してください。
まずAGENTS.md、README.md、docs/以下と既存の差分を確認してください。

企画は「写真から編集可能な音楽を生成するWebアプリ」です。
結婚式の写真なら、明るく温かなコード進行が入った状態から始められます。
ユーザーはコード・テンポ・伴奏パターンを直接編集でき、
「後半をもっと感動的に」などのAI支援も使えます。
ホスティングはCloudflareで、3時間のハッカソンの発表時に公開サイトを操作します。

MVPは写真1枚、8小節、4拍子、鍵盤音色のコード伴奏です。
音楽の正本は編集可能な構造化データにしてください。
AIは画像の印象・音楽設定・編集案を提案し、
アプリで音符を組み立ててブラウザ再生とMIDI出力に共用してください。
AI編集は変更点の説明・試聴・適用・破棄を用意し、直前の編集を元に戻せるようにします。

まずCloudflareへの最小公開と、固定曲の再生・直接編集を進めてください。
React + TypeScriptを第一候補とし、必要なサービス・ライブラリは公式資料で確認してください。
認証不足なら具体的に報告し、依存しない部分の実装は進めてください。
サンプルやモックは画面で明示してください。
PV制作・音声生成API・本格的なDAWは今回の必須範囲に含めません。

実装後は必要な検証を行い、READMEの起動手順とdocs/TASKS.mdの進捗を更新してください。
```
