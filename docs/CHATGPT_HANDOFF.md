# ChatGPTへの開発依頼文

このリポジトリにアクセスできるChatGPT / Codexで、以下を最初の依頼に使う。
通常のChatGPTでファイル参照ができない場合は、READMEとdocsの内容も渡す。

```text
このリポジトリのPV Paletteを実装してください。
まずAGENTS.md、README.md、docs/以下と現在の実装を確認してください。

目標は、3〜5枚の画像とテーマから、AIで構成・テロップ・音楽を生成し、
15秒のPVとしてブラウザ上で再生できるサイトです。
ホスティングはCloudflareで、発表時に公開URLを操作します。

まずdocs/TASKS.mdの「公開と接続の確認」と「画面と再生」を進めてください。
React + TypeScriptを第一候補とし、Cloudflareの現行公式資料を確認して、
開発・ビルド・公開できる最小構成を用意してください。
外部サービスの認証情報が不足する場合は具体的な不足を報告し、
認証情報に依存しない画面・プレイヤーの実装を進めてください。
音楽生成サービスは未選定です。実際のAPI利用可否を早めに確認してください。

モック・事前生成例はその旨を画面に表示してください。
MP4書き出し・ログイン・課金・履歴は今回の必須範囲に入れないでください。
実装後は必要な検証を行い、READMEの起動手順とdocs/TASKS.mdの進捗を更新してください。
```

## 次回以降の依頼

```text
README、AGENTS.md、docs/TASKS.mdと現在の差分を読み、
未完了のMVPタスクを優先順に進めてください。
実装済みの内容は維持し、最後に検証結果と残作業を記録してください。
```
