# 画像分析APIと音楽生成担当への受け渡し契約を用意する

状態：下書き（GitHub未投稿）。LOCAL-002はGitHubのイシュー番号ではない。

追加要望（2026-11-07）：利用者がPCから3〜5枚程度の写真を選択する。以下の「1枚」や「複数拒否」は旧案であり、この追加要望を優先する。暫定で1〜5枚を一括分析し、全画像に対する1組の印象を生成側に渡す。下限枚数と最終契約は確認待ち。1枚あたりと合計の上限を決め、どれか1枚が不正なら全体を送信しない。

## 背景・目的

`src/main.tsx` は画像をブラウザ内で表示するだけで、AIやサーバーAPIは未接続。`docs/ARCHITECTURE.md` の `POST /api/songs` は画像からSongまで返す未実装の案であり、音楽生成は別担当である。画像の印象を安全に分析し、その担当が消費できる検証済みの結果を返す境界を設ける。曲・音符を作らない。

## 対象範囲

- 音楽生成担当と入力・出力・責任分担をすり合わせ、決定した契約を `docs/ARCHITECTURE.md` に記録する。以下は調整用の案であり既存の確定仕様ではない。
- 案：`POST /api/image-analysis` に `multipart/form-data` の画像1枚と任意の用途・雰囲気の短いテキストを送り、成功時は `{ "version": 1, "moods": ["温かい", "明るい"], "description": "柔らかな光が印象的" }` を返す。`moods` は1〜5個、各1〜30文字、`description` は1〜200文字、任意テキストは200文字以下とする案。推測や感情は事実として断定せず、曲設定やSongは含めない。文字数やフィールドは生成担当との合意で変更可。合意前の案を確定仕様と見なさない。
- Workerで画像をAIに渡し、プロバイダーの応答をパース・検証した結果だけを返す。AIプロバイダー、モデル、データ保持・利用条件、対応形式、上限、料金と応答時間は未選定。公式資料で確認し、利用可能なアカウント・秘密情報を明記する。モックを使う場合は実分析として扱わない。
- 現行UIはJPEG/PNG/WebP・10 MiB以下。実際の送信上限は採用先とCloudflareの制限を確認し、両側で同一の値を使う。空、複数、形式不一致、破損、過大入力を拒否し、Content-Typeだけを信用しない。リクエスト全体にも上限を適用する。
- タイムアウト、外部サービス失敗、無効な応答、設定不足を区別できる安定したエラー形式を定義する。画像・入力・応答・キーをログに残さず、写真をアプリで永続保存しない。秘密情報はWorkerの秘密情報として設定し、ブラウザやGitに含めない。
- Cloudflare静的アセットとAPIを共存させる。`wrangler.jsonc` は現状静的配信のみであり、WorkerエントリとAPIルーティングを追加する。SPA設定時のルーティングは [Cloudflare公式設定](https://developers.cloudflare.com/workers/static-assets/binding/) を参照する。リクエストの上限は [Workers公式制限](https://developers.cloudflare.com/workers/platform/limits/) と採用先の現行資料で確認する。

## 対象外

Song・コード・音符・再生・MIDIの生成と分析結果からの曲への反映、AI編集、画像の永続保存、デプロイそのもの。

## 受け入れ条件

- [ ] 有効な画像1枚から実際の画像分析を行い、合意した形の印象と短い説明を返す。画像分析と固定サンプルが区別できる。生成担当が必要とする追加項目は合意して契約に反映する。
- [ ] 未選択、複数、空、不正形式・破損、上限超過、任意テキスト超過を拒否し、AIに転送しない。ファイル名やMIMEの偽装も検証する。
- [ ] 不正JSON、欠落・型違い・長さ超過のAI応答は成功として返さず、エラーが分かる。タイムアウト、通信障害、認証設定不足も安全なエラーとなり、秘密情報や画像を漏らさない。
- [ ] APIパスはSPAのHTMLでなく契約どおりの応答を返し、既存の静的画面は表示できる。写真の永続保存や入力内容のログ出力は行わない。
- [ ] 契約、上限、設定手順、採用先の画像送信先とデータの扱い、実測した確認・未確認を資料に残す。公開環境のコスト対策と利用制限の方法・未対応事項を明示する。

## 検証方法

- 自動：正常入力、境界値、偽装・破損、複数ファイル、超過、各種不正AI応答、タイムアウト・認証不足を実際のAPI境界で確認。外部AIはテスト時に差し替え、転送しないケースを検証する。`npm run typecheck`、`npm test`、`npm run build`。
- `npm run cf:dev` でAPIと静的画面を確認。実画像での分析は採用先のアカウント・秘密情報が必要。公開URLでの確認はCloudflare認証・デプロイ後に行い、未実施なら記録する。ログとブラウザ配信物に秘密情報や画像が含まれないことを確認する。

## 優先度・依存関係

- 優先度：画像AI接続の先行作業。`AGENTS.md` の公開・固定再生を優先した後に着手。
- 先行イシュー：なし。音楽生成担当との契約合意が統合の前提。CloudflareとAIプロバイダーのアカウント・認証情報・利用枠が必要。認証不足なら具体的に残し、モック検証と実分析を区別する。
