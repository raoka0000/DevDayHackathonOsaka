## 変更

- `src/music.ts`：Track.notes、全音符検証、音符置換、小節/全体再生成、履歴操作。既存生成の0.45拍・3.8拍を維持。
- `src/midi/PianoRoll.tsx`：音名・拍目盛り、全音符表示、追加/選択/削除/ドラッグ/リサイズ/数値入力、再生線、エラー、取消。
- `src/main.tsx`：Trackの保持とUndo、再生成の範囲説明・適用/取消、編集開始時停止。
- `src/player.ts`：保存音符を予約し、音声クロックの拍位置を通知。再生再開待ちの古いContextは予約しない。
- MIDIは保存音符を出力し、空配列でもテンポ・拍子・32拍終端を保持。

仕様の補足：音符の所有小節は開始拍で決める。小節をまたぐ音符は開始小節の再生成で全体を置換し、他の小節の再生成では保持する。残存音符との重複は適用を拒否する。数値の長さ入力は既存生成値を扱うため0.25拍以上の任意精度を許可し、ドラッグリサイズは0.25拍刻みとした。再生成確認は手編集有無にかかわらず毎回表示する。
