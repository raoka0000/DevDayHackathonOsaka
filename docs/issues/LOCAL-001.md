# LOCAL-001：ピアノロールで音符を直接編集できる画面を作る

状態：GitHub投稿済み（[#1](https://github.com/raoka0000/DevDayHackathonOsaka/issues/1)）／未実装。
このファイルは起票時の控え。以後はGitHubの最新本文を正本とする。
作成日：2026-11-07。
要望：「MIDIのように操作できる画面を作成する」。本案では、縦軸が音高、横軸が時間のピアノロール上で音符を編集する意味として扱う。MIDIファイル読み込みや外部MIDI機器接続は含めない。

## 背景・目的

現在の `src/main.tsx` は小節ごとのコード、テンポ、伴奏パターンを変更できるが、音符そのものは編集できない。`src/music.ts` のSongはコード設定だけを保持し、notesForで音符を生成する。`src/player.ts` とmidiForはそれぞれnotesForを呼ぶため、画面だけで音符を動かしても再生・出力に反映されない。

8小節の伴奏をピアノロールに表示し、音の高さ・位置・長さを直接変え、同じ編集結果を聴いてMIDIとして書き出せるようにする。

根拠：`AGENTS.md` の構造化データと再生/MIDI共用の方針、`docs/ARCHITECTURE.md` のNoteEvent、`docs/PRODUCT.md` の追加機能、`tests/music.test.ts` の既存検証。既存資料ではピアノロールはMVP外の追加機能であり、本イシューは今回の明示的な要望として起票する。MVP全体の必須条件は変更しない。

## 対象範囲

- 1トラック・8小節・4拍子のピアノロール。鍵盤または音名、半音ごとの行、小節・拍の目盛り、音符ブロック、再生位置を表示する。
- 固定サンプルと現在の伴奏音符を表示し、追加・選択・削除、ドラッグによる音高/開始位置変更、端のドラッグによる長さ変更を可能にする。
- 選択音符に対する入力欄またはキーボード操作も設け、ドラッグだけに依存せず音高・開始位置・長さを編集できるようにする。
- 編集音符を構造化データとして保持し、画面・再生・MIDI出力で同じ検証済み音符を利用する。再描画でnotesForの結果に戻さない。
- Undoに音符編集を含める。再生中の変更では演奏を停止し、先頭に戻す。
- コード/パターン編集と音符編集が衝突する場合の再生成を明示し、無断で手編集を消さない。
- READMEとデータ設計資料に実装後の操作・制約・データ契約を反映する。

### 初版の仕様案

以下は曖昧な要望を実装可能にするための提案値。変更する場合は理由と決定値をイシュー/引き継ぎに残す。

- 時間は0以上32拍未満、追加・移動・リサイズは1/4拍（16分音符）刻み。追加音符の長さは1拍、最短長は1/4拍、終端は32拍以下。
- 既存生成音符の長さ3.8拍/0.45拍は表示しただけでは量子化しない。リサイズした音符の長さのみスナップし、移動で既存の長さは変えない。
- 音高はMIDI番号48〜84を初版の編集範囲とし、半音単位で操作する。ベロシティは既存値を維持し、追加時は78。強弱編集は含めない。
- コード変更では対象小節、パターン変更では全小節を再生成する。手編集済みの対象範囲を置換する場合は、範囲と編集消失を画面で説明し、適用/キャンセルを選べるようにする。Undoで設定と音符を一緒に復元する。テンポ変更では音符の拍位置・長さ・音高は変えない。
- 同じ音高の時間的な重なりは、再生とMIDIの差異を避けるため初版では拒否し、説明を表示する。異なる音高の同時発音は許可する。
- PCブラウザのマウスとキーボードを初版の操作対象とし、狭い画面ではグリッド内をスクロールできるようにする。

## 対象外

MIDIインポート、外部MIDIキーボード、録音、複数トラック、音色追加、ベロシティ編集、ペダル、複数音符の一括編集、Redo、曲長/拍子変更、AI接続、永続保存、本格DAW化。公開先の作成・デプロイは別作業。

## 受け入れ条件

- [ ] 初期サンプルの全音符が音高・開始位置・長さに対応するブロックとして表示され、8小節と拍位置が読める。表示やスクロールだけでは音符データが変化しない。
- [ ] 空き位置への追加、音符の選択・削除、音高/時間方向の移動、長さ変更ができる。選択状態と現在値が分かり、同じ変更をドラッグ以外の方法でも行える。
- [ ] 音高範囲外、負の開始位置、0以下の長さ、32拍を超える終端、非有限値、不正なベロシティをデータ境界で拒否する。画面の範囲外操作では既存曲を壊さず、適用できない理由が分かる。
- [ ] 同音高の重複を作る操作を拒否し、異なる音高の和音は編集・再生できる。ドラッグをキャンセルすると元の状態に戻る。
- [ ] 追加・移動・リサイズ・削除を各1回の編集としてUndoできる。ドラッグ中の各イベントで履歴を消費しない。キャンセルした操作は履歴に積まない。
- [ ] 手編集後の音高・開始拍・長さ・ベロシティが再生に渡す音符とMIDIのnote on/offに一致する。削除した音符は鳴らず、出力にも含まれない。
- [ ] テンポ変更では拍単位の音符が保たれ、再生速度とMIDIテンポだけが変わる。コード/パターン再生成は説明した範囲だけを置換し、キャンセルでは設定・音符の両方を維持する。Undoで置換前に戻る。
- [ ] 再生中に音符編集を始めると予約音・発音中の音が止まり、位置が先頭に戻る。再生ボタン連打・停止・再再生で音が重ならず、再生位置表示は実際の演奏クロックに追従する。
- [ ] 全音符削除後も無音の8小節として扱え、再生・MIDI出力で例外が出ない。MIDIにはテンポ・4/4・終端32拍が残る。
- [ ] 写真プレビュー、固定サンプル表示、コード/パターン編集、既存UndoとMIDIダウンロードが引き続き利用できる。横長グリッドはスクロール可能で、主要ボタンを隠さない。

## 検証方法

- 自動：`npm run typecheck`、`npm test`、`npm run build`。
- `tests/music.test.ts` 等で追加/移動/リサイズ/削除、境界値、同音高重複、キャンセル、Undo、コード再生成の対象範囲を検証する。表示前後で既存3.8拍/0.45拍の音符が変化しないことも確認する。
- 編集後の既知音符列を期待値として、再生に渡すデータとMIDI解析結果を比較する。ピッチ、note on/off時刻、ベロシティ、テンポ、拍子、終端32拍、全削除時を確認し、表示値だけのテストにしない。
- PCブラウザで追加→移動→長さ変更→削除→Undo→再生→停止→MIDIダウンロードを行う。ドラッグのキャンセル、先頭/末尾境界、コード/パターン置換のキャンセルと適用、テンポ変更、キーボード/入力欄操作、狭い画面のスクロールを確認する。
- 音声を実聴し、外部MIDI対応ソフトで編集した音高・タイミング・長さ・テンポが一致することを確認する。デプロイ後は公開URLでも主要操作を再確認する。実機・公開環境がない場合は未検証として残す。
