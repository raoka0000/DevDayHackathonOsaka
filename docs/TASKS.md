# 3時間の実装タスク

資料準備済み。以下の実装タスクは未着手。
時間は目安とし、詰まった場合は追加機能より完成条件を優先する。

## 0〜20分：公開と接続の確認

- [ ] React + TypeScriptとCloudflare向けの最小構成を作る。
- [ ] 開発・ビルド・デプロイの手順をREADMEに記載する。
- [ ] Cloudflareに公開し、URLを記録する。
- [ ] 音楽生成サービスを選び、ジョブ作成から音源取得まで確認する。
- [ ] 構成生成AIへの接続を確認する。

認証情報・課金などで使えない機能は、状況と必要な対応を記録する。
接続を待つ間も、画面とプレイヤーは実装できる。

## 20〜60分：画面と再生

- [ ] 画像3〜5枚の選択・検証・プレビュー。
- [ ] タイトル・説明・雰囲気の入力。
- [ ] 固定の構成を使った15秒タイムライン。
- [ ] フェード・ズーム・テロップと再生操作。
- [ ] モック表示と本番生成を画面で区別する。

## 60〜100分：構成生成

- [ ] サーバー側から構成生成AIを呼ぶ。
- [ ] 画像・テーマから構成と音楽プロンプトを作る。
- [ ] 応答形式・画像ID・表示時間・テロップを検証する。
- [ ] 生成中・エラー・再試行の表示。

## 100〜135分：音楽生成

- [ ] 音楽ジョブの作成と状態確認。
- [ ] 音源の読み込み・映像との同期。
- [ ] 停止・再再生・終了時の動作。
- [ ] 待機時間の上限・API失敗・二重送信の対処。

## 135〜160分：公開環境の検証

- [ ] 型チェック・ビルド。
- [ ] 公開環境で画像選択からPV再生まで通す。
- [ ] 不正な入力・API失敗時の表示を確認する。
- [ ] 秘密情報がブラウザや配信物に含まれていないことを確認する。

## 160〜180分：発表準備

- [ ] 使用可能なサンプル画像と事前生成例を用意する。
- [ ] 公開URLを別ブラウザから開く。
- [ ] 発表端末の音声出力を確認する。
- [ ] 新規生成と事前生成例の両方で発表を練習する。
- [ ] 実装済み・未実装・既知の制限をREADMEに反映する。
