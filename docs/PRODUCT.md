# 企画・受け入れ条件

## コンセプト

PV Palette（仮称）は、画像から構成・コピー・音楽を揃えたPVを作るWebアプリ。
編集や選曲に慣れていない店舗担当者・イベント主催者・クリエイターを対象とする。

## MVPの仕様

| 項目 | 初期仕様 |
| --- | --- |
| 入力画像 | 3〜5枚。JPEG / PNG / WebP。1枚10MB以下を目安に実装時に検証 |
| テキスト入力 | タイトル・短い紹介文 |
| 雰囲気 | 爽やか・かっこいい・感動的の3択から開始 |
| 映像 | 15秒・横長16:9。フェードと緩やかなズーム |
| 構成 | 選択画像を使い、全シーンの時間を合計15秒にする |
| テロップ | AIが日本語で生成。画面内に収まる長さに制限 |
| 音楽 | 雰囲気に合った歌なしの音楽を外部サービスで生成 |
| 再生 | ユーザーが再生ボタンを押して開始。終了・再再生で映像と音を同期 |
| 保存 | セッション内での利用を基本とし、永続的な履歴は作らない |

## 画面

1. 作成画面：画像選択とプレビュー、テキスト入力、雰囲気、生成ボタン。
2. 生成中：構成作成中・音楽生成中の状態。失敗理由と再試行。
3. 完成画面：PVプレイヤー、再生・停止・最初から再生、作成画面に戻る。

1ページ内の状態切り替えで実装してよい。サンプル画像と完成例への導線も用意する。

## 受け入れ条件

- [ ] 公開URLを別のブラウザで開ける。
- [ ] 画像枚数・形式・サイズや必須入力の不備を表示できる。
- [ ] 自分で選んだ画像が完成PVに反映される。
- [ ] 入力テーマに応じてAI生成の構成・テロップが変わる。
- [ ] 実際に生成した音楽が鳴り、画像・テロップと同期する。
- [ ] 再生ボタンから開始でき、終了時には音楽も停止する。
- [ ] 二重生成を防ぎ、API失敗時に再試行できる。
- [ ] 事前生成例と新規生成を区別して表示する。
- [ ] 発表会場で音声が出ることを確認する。

## 発表シナリオ

カフェの外観・コーヒー・店内の画像を選び、「週末に立ち寄りたくなるカフェ」を入力。
生成を開始し、完成したPVを音付きで再生する。生成に時間がかかる場合は、
「このサイトで事前生成した例」と説明して完成例を再生する。

新規生成の失敗や制限は、そのまま説明する。完成例を新規生成結果として扱わない。
