# 企画・受け入れ条件

## コンセプト

PhotoChord（仮称）は、写真を音楽づくりの出発点にするWebアプリ。
楽典やDAWの操作に詳しくない人も、最初から音が入った状態で作曲を始められる。
主な利用場面は結婚式・旅行・家族の思い出などの写真に合う伴奏づくり。

## 結婚式の写真の例

1. 写真を選ぶと「祝福・明るさ・温かさ」という印象が提案される。
2. 初期案としてCメジャー・100 BPM・8小節の伴奏が入る。
3. 例として `C | G | Am | F | C | G | F | C` を再生する。
4. テンポを90 BPMに変え、伴奏をブロックコードから分散和音にする。
5. 「後半をもう少し感動的に」と頼み、後半の変更提案を比較・試聴して適用する。
6. 気に入った曲をMIDIでダウンロードする。

この進行と設定は一例。写真の種類から固定で決めつけず、AIの解釈とユーザーの好みを反映する。
「明るい」の感じ方には個人差があるため、説明は提案として表示する。

## MVP仕様

| 項目 | 初期仕様 |
| --- | --- |
| 入力 | 写真1枚。JPEG / PNG / WebP。上限は実装時にAPI制限と併せて設定 |
| 任意入力 | 用途・希望の雰囲気 |
| 初期生成 | 画像の印象、短い提案理由、キー、テンポ、コード進行 |
| 曲の長さ | 8小節・4拍子。秒数はテンポで変わる |
| 演奏 | 1つの鍵盤音色、コード伴奏。ブロックコード／分散和音 |
| 直接編集 | 小節ごとのコード選択、60〜160 BPM、伴奏パターン |
| キー | 初期生成後は表示のみ。対応キー・コードの候補を実装時に限定 |
| AI編集 | 自然言語からコード・テンポ・パターンの変更を提案 |
| 提案操作 | 変更点・理由、試聴、適用、破棄、直前の編集を元に戻す |
| 再生 | 再生・停止・最初から再生。再生中の編集は停止して反映 |
| 出力 | 編集結果のMIDIファイル。テンポ・拍子・音符を含む |
| 保存 | セッション内。永続履歴・アカウントは作らない |

メロディ生成、ドラム、ピアノロールでの音符ドラッグ、音色追加、WAV/MP3出力、
複数画像、PV制作、共有、課金は追加機能とする。
MVPの音楽は伴奏であり、歌や完成されたフル楽曲を約束しない。

## 画面構成

1ページに画像・印象、再生コントロール、8枚の小節カード、AI編集欄を配置する。
各小節にはコード選択と再生位置を表示し、初心者向けに平易な説明を添える。
AI提案は現在の曲と変更箇所を比較できるようにする。

## 受け入れ条件

- [ ] Cloudflareの公開URLを別ブラウザで開ける。
- [ ] 画像入力を検証し、外部AIへの送信を説明する。
- [ ] 実際の画像分析から音楽の初期案が入る。
- [ ] 8小節の伴奏が再生され、再生位置が見える。
- [ ] コード・テンポ・パターン変更が再生に反映される。
- [ ] 自然言語の編集依頼から変更内容・理由を確認し、試聴できる。
- [ ] 提案の適用・破棄と、直前の編集を元に戻す操作ができる。
- [ ] 編集後のMIDIを別のMIDI対応ソフトで開き、音符・テンポ・長さを確認できる。
- [ ] 不正なAI応答・通信失敗でも編集中の曲を失わず、再試行できる。
- [ ] サンプルと実際のAI生成を区別し、会場で音声が出る。

## 発表

公開サイトで結婚式写真を入力→初期伴奏を再生→直接編集→AIで後半を変更→
変更前後を聴く→MIDIを書き出す。「写真から始めて、自分で曲を育てられる」と伝える。
生成待ちに備えてサンプル曲も用意し、事前に作ったものと説明して使う。
